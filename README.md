# Prerak Singh — QA Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `prerak_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

You can also open the folder in VS Code or Eclipse and edit `index.html`.

## Personalize before publishing
- Add your professional email and LinkedIn URL in the Contact section.
- Add a profile photo if you want one.
- Add more project links and screenshots as you complete projects.
- Review the skills list so it reflects what you can confidently discuss in an interview.
